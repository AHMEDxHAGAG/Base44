# Behavior checklist

- [x] Header is fixed and transparent at the top.
- [x] Header becomes white after 20 px of scroll.
- [x] Desktop mega menus are keyboard-operable disclosures.
- [x] Mobile navigation is a closable modal-like sheet.
- [x] Hero tabs swap all six visible assets.
- [x] Hero animation can be paused and resumed.
- [x] Build-card and button hover states are limited to pointer-capable wide layouts.
- [x] FAQ is a single-open accessible accordion with the first item initially open.
- [x] All visible links use the original destination where available.
- [x] Native page scrolling and fixed-header behavior are retained.
- [x] Reduced-motion preferences suppress autoplay and decorative transitions.
